# Step 8 - Receive and Process Authentication Response

## Goal

After the Biometric Authentication Request is processed, the Aadhaar Authentication Server returns an **Authentication Response XML**.

The response indicates whether the resident's biometric data has been successfully authenticated and provides transaction details along with any applicable error information.

---

## Response Workflow

```text
Biometric Authentication Request
                │
                ▼
Aadhaar Authentication Server
                │
                ▼
Authentication Response XML
                │
                ▼
Validate Response
                │
                ▼
Read Response Attributes
                │
                ▼
Determine Authentication Result
```

---

## Example Success Response

```xml
<?xml version="1.0" encoding="UTF-8"?>

<AuthRes
    ret="Y"
    code="100"
    txn="BIO202607161600001"
    ts="2026-07-16T16:00:03"/>
```

> A value of `ret="Y"` indicates that the resident's biometric information was successfully authenticated.

---

## Example Failure Response

```xml
<?xml version="1.0" encoding="UTF-8"?>

<AuthRes
    ret="N"
    err="330"
    txn="BIO202607161600001"
    ts="2026-07-16T16:00:03"/>
```

> A value of `ret="N"` indicates that biometric authentication was unsuccessful.

---

## Response Attributes

| Attribute | Description                                                   |
| --------- | ------------------------------------------------------------- |
| `ret`     | Authentication result (`Y` = Success, `N` = Failure).         |
| `txn`     | Transaction ID received from the authentication request.      |
| `ts`      | Timestamp generated by the Aadhaar Authentication Server.     |
| `code`    | Success code (if applicable).                                 |
| `err`     | Error code returned when authentication fails.                |
| `info`    | Additional information returned by the server (if available). |

> The exact response attributes may vary depending on the Aadhaar Authentication API version and your AUA/ASA integration.

---

## Processing the Response

After receiving the Authentication Response XML:

1. Verify that the HTTP request completed successfully.
2. Parse the XML securely.
3. Confirm that the root element is `AuthRes`.
4. Match the `txn` attribute with the original request.
5. Read the `ret` attribute to determine the authentication result.
6. If authentication failed, read the `err` attribute and handle the error appropriately.
7. Store only the information required for auditing and transaction tracking.

---

## Success Scenario

If:

```text
ret = "Y"
```

The resident has been successfully authenticated using biometric authentication.

Your application can now:

* Grant access to the requested service.
* Continue the business workflow.
* Record the successful authentication transaction.
* Display a success message to the user.

---

## Failure Scenario

If:

```text
ret = "N"
```

The authentication request was processed, but the biometric authentication was unsuccessful.

Possible reasons include:

* Fingerprint did not match.
* Iris authentication failed.
* Poor biometric quality.
* Invalid biometric data.
* Authentication request validation failed.

Your application should:

* Read the returned error code.
* Display an appropriate user-friendly message.
* Log the Transaction ID for troubleshooting.
* Allow the resident to retry the biometric capture if appropriate.

---

## Example Error Codes

| Error Code | Description                              |
| ---------- | ---------------------------------------- |
| 300        | Biometric data did not match             |
| 330        | Biometric quality insufficient           |
| 400        | Invalid Aadhaar Number or Virtual ID     |
| 500        | Invalid Digital Signature                |
| 569        | Authentication request validation failed |

> The error codes above are provided as examples only. Refer to the official UIDAI documentation or your AUA/ASA implementation guide for the complete list of supported response codes and their meanings.

---

## Validation Checklist

After processing the response, verify that:

* The Transaction ID matches the original request.
* The response XML is well-formed.
* The `ret` attribute has been evaluated.
* Error codes have been handled appropriately.
* No sensitive information has been written to application logs.

---

## Best Practices

* Always validate the Authentication Response XML before using its contents.
* Never rely solely on the HTTP status code.
* Correlate every response using the Transaction ID.
* Display user-friendly messages instead of raw error codes.
* Log only non-sensitive information required for monitoring and auditing.

---

## Authentication Complete

If the response indicates success (`ret="Y"`), the Aadhaar Biometric Authentication process is complete.

```text
Collect Input
        │
        ▼
Generate PID XML
        │
        ▼
Encrypt PID XML
        │
        ▼
Generate HMAC
        │
        ▼
Create Authentication Request XML
        │
        ▼
Digitally Sign XML
        │
        ▼
Send Authentication Request
        │
        ▼
Receive Authentication Response
        │
        ▼
Biometric Authentication Successful ✅
```

---

## Notes

> A successful response confirms that the resident's biometric information has been successfully verified against the Aadhaar database.

> Do not store raw biometric data, PID XML, decrypted biometric information, session keys, or any other sensitive authentication data after the authentication process is complete.

> Retain only the minimum information required for audit, reconciliation, and regulatory compliance, in accordance with UIDAI guidelines and your organization's data retention policy.
